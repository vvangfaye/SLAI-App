# 今日时长与出勤状态

首页和考勤页今天的详情使用学院闸机流水估算时长，解决学校当天汇总尚未生成或为 0 的情况。估算不写入学校缓存，不用于判定合格，也不加入学校月度统计。

- 只计成功的学院进出：保留接口 `swipeType` 字段，识别“教学楼”等学院类型。类型缺失时识别学院通道，例如“闸机-西1-入／出”；方向缺失时可以从这类通道推断。
- 宿舍优先排除：地点或通道包含“宿舍／公寓／寝室”，包括“宿舍_道闸入／出”，均不计入时长，也不改变学院出勤状态。
- 每次进门与下一次出门配对，多段相加，离校期间不计时。例如 09:00–12:00、14:00 再入校，15:30 的估算为 4 小时 30 分。
- 最后有未闭合的进门时显示“出勤中”，计到当前时间，提示现在离开的累计时长及个人目标预计达成时间。已出门时显示“未出勤”，只显示已完成时段；这不代表学校认定缺勤。
- 同秒同方向重复记录只计一次；连续进门保留最早一次。各段按秒累计后向下取整到分钟。
- 缺少进门的出门不补算；同秒相反方向或未识别的记录会中断不确定的时段，并提示核对。只保留已确认的累计时长，不把未知情况当成准确的 0 或持续在校。
- 仅估算当天，不从昨天未闭合的进门延续计时。跨日或漏刷造成的缺失时段需以学校后续汇总核对。

页面可见时每 15 秒更新本地估算，每分钟重新读取流水，也可手动刷新。状态基于上次成功返回的记录，学校上传可能有延迟。刷新失败时冻结在上次成功读取的时间，显示“待更新”；重新进入页面会重取记录。离开页面停止计时与轮询，午夜切换日期并清空上一天估算。

验证覆盖多次进出、宿舍过滤、重复记录、缺失记录、失败开门、秒数累计、日期切换、页面隐藏后的迟到响应及刷新失败恢复。真实记录的页面显示仍需真机验收。
