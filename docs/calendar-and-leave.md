# 日历、年假与个人日程（2026-09-13）

本次改动在本地实现，未上传、提审或发布新版本。

## 使用入口

- 日常：本月有效 / 应到天数、个人年假余额、下一节课、未来七天的两条个人日程、考勤更新时间。
- 课表与考勤：放假“休”、调休补班“班”、请假“假”、个人日程“事”。点击日期查看详情，可进入请假记录或添加日程。
- 我的 → 年假与请假：按年设置额度（含手动结转）、此前已用、估算规则；记录请假并编辑状态。
- 我的 → 个人日程：添加、编辑、完成与恢复日程。数据只在本机，无后台通知。
- 课表右上角或我的 → 导出课表：选择日期范围或整个学期，生成 `.ics`，通过微信文件分享。无需服务器、额外域名或日历读取权限。

## 节假日来源及边界

仅收录已核验的 2026 年国务院放假调休安排，33 个放假日期及 6 个补班日期。来源：[国办发明电〔2025〕7号](https://www.gov.cn/zhengce/zhengceku/202511/content_7047091.htm)，2026-09-13 核对原文。日期数据在 `miniprogram/utils/holidays.js`，可离线使用。

“休”代表公告中的整个放假调休区间，不声称其中每一天都是法律意义上的法定假日。其他年份显示“该年度节假日数据未收录”，不会将 2026 日期复制过去或推测调休。后续年度需要核对官方通知后更新代码包。国家放假不改变课表的教学周、课程时间，也不替学校判定考勤。

## 年假与请假

未找到并验证学校年假余额、审批记录接口。本版是明确标注的本机个人账本，不会向学校提交请假或将手动状态说成学校审批结果。学校月汇总返回的 `isLeave` 单独显示为“学校标记：请假”，不能据此扣年假。

- 未设置额度时显示“设置”，不预填任何天数或劳动法规则。
- 剩余 = 年度额度 − 此前已用 − 个人记录中已批准的年假；预留后可用 = 剩余 − 待审批年假。
- 计划、已取消、其他类型请假不扣年假。未来已批准记录也占用额度，故界面称“已批准”，而非已经休完。
- 半天以 0.5 天记录，上午 / 下午定位时段，活动记录重叠时拒绝重复录入；编辑原记录不会二次累加。
- 默认手动填写；可设置按调休工作日或日历天估算，用户点击“填入”后确认天数。课程冲突以 12:00 为上午 / 下午分界，仅供排期参考。
- 保存时固定扣假天数，以后更改估算规则不会追溯更改旧记录。余额可负数并显示超额提醒。
- 跨年请假要求分年度录入，额度不自动结转；未知年度不提供工作日扣假估算。
- 使用独立 `hetao.personal-planner.v1` 缓存，属于本机个人记录，切换校园账号或清除校园数据时保留。损坏缓存不会被默认值、新增记录覆盖。

## 学校月统计

原月汇总请求保持不变，从同一响应的 `stats` 提取学校指标并按月缓存。`requiredPunches` 优先，缺失时使用 `totalWorkdays`；有效天数优先 `totalValidPunches`，仅当 `actualWorkdayPunches` 与 `actualRestdayPunches` 都存在时才相加。原始字段的学校实际口径仍需真机与学校页面核对。

不把缺失当零，不从日合格数量猜月指标，不使用原 Android 客户端自行折算规则。`maxAllowedRestdayPunches` 不作为年假余额。每次成功同步替换当前月份指标（缺失项回到未知），其他月份保留；新账号同步清空旧账号统计。

异常列表仅收集已过去日期中学校明确判定未达标且没有学校请假标记的记录。未同步、未知状态、未来日期和今天不判定为异常；点击查看现有打卡明细。

## 导出及验证

ICS 按教学周枚举课程，使用北京时间换算 UTC 时间，保留名称、教室与教师，稳定 UID，文本转义和按 UTF-8 字节折行。只允许导出真实同步课表；生成后用户选择分享位置，取消明确提示，临时导出文件在分享结束后清理。文件导出不是系统日历持续订阅，调课需重新导出，建议导入独立日历并替换旧日历以避免重复。

官方 API：[文件分享](https://developers.weixin.qq.com/miniprogram/dev/api/share/wx.shareFileMessage.html)、[写文件](https://developers.weixin.qq.com/miniprogram/dev/api/file/FileSystemManager.writeFile.html)。
