# 河套日常

采用独立名称与视觉设计的微信原生校园生活小程序；学校接口适配参考 [wangjt23/SLAIer-APP](https://github.com/wangjt23/SLAIer-APP)。使用 JavaScript / WXML / WXSS，无需 npm 安装或构建。

已接入学校登录、当前学期课表同步和按月考勤汇总，保存在本机供离线查看。独立验证页已通过真实账号手机测试（本次考勤测试需 VPN）；新接入的主页面及月汇总、节次时间接口仍需手机验收，尚未发布正式版。详见 [验证记录](docs/login-verification.md)。

## 启动

1. 在微信开发者工具中导入本目录，项目根目录包含 `project.config.json`。
2. 项目已配置本次测试的 AppID；其他开发者请替换为自己的 AppID。真机预览、上传以实际账号权限为准。
3. 选择「普通编译」，在首页「同步」或「登录」本人登录；校外访问考勤请开启 VPN。在「我的」同步课表和本月考勤，在考勤页同步所选月份。登录页默认开启「记住登录」，成功后使用微信加密缓存保存凭据。下次读取校园数据时自动登录；退出登录会删除凭据。关闭此选项则仅本次登录。
4. 编译后查看「日常 / 课表 / 考勤 / 我的」。首次打开使用明确标注的虚构演示数据，演示学期与记录随当前日期生成。

已完成开发者工具编译和独立登录验证页的手机测试；新增登录页编译显示正常，主页面真实同步的完整真机验收仍待完成。

## 已实现

- 今日课程、今日时长、个人目标进度。
- 周课表、前后翻周、返回本周；按课程教学周过滤，支持单双周数组。
- 月份切换、每日考勤、已同步记录的合格天数及累计时长。
- 个人时长目标、首页课程开关。
- 学校同步、本地缓存、数据清除和演示模式。
- 2026 节假日 / 调休标记、学校月度考勤进度、未达标待核对列表。
- 本机年假账本（含半天与审批状态）、请假估算与课程冲突、个人日程及双日历标记。
- 下一节课、更新时间、课表导出 `.ics`。详见 [日历与年假说明](docs/calendar-and-leave.md)。
- 严格验证日期、时间、教学周、重复日期与时长范围；失败不覆盖旧数据。

学校日判定仅来自 `qualified`，不以个人目标推断。月度指标来自学校返回的 `stats`，与已同步日记录汇总分开，不做每周最多 5 天折算。时长来自学校每日汇总，不计算实时闸机流水。年假为用户维护的个人记录，目前不自动同步学校余额。

## 接入真实学校数据

原 App 使用 Android WebView Cookie 与注入脚本获取学校数据；微信小程序没有对应的任意网页脚本注入及 Cookie 读取接口，不能直接照搬。微信官方文档还指出个人类型小程序暂不支持 `web-view`，其他网页需配置业务域名。

学校支持的身份绑定与只读数据 API 是长期接入选择之一。2026-09-11 公开链路检查还发现 AD FS 普通表单与 wx.request 手动重定向支持，实现了不经过后端的直接登录，已通过本次真实账号的手机验证；用户开启 VPN 后确认考勤也可用。`wx.login` 仅识别微信身份，不能直接登录校园账号。具体流程、平台差异与接口约定见 [接入设计](docs/integration.md)。已实现主页面手动同步；未实现订阅提醒、后台轮询、网页抓包或 APK 更新。

- 产品名称统一为「河套日常」，采用暖纸色、松绿色和紧凑日记式布局，不使用参考项目的品牌素材。
- 底部保留「日常 / 课表 / 考勤 / 我的」，首页课程缩成紧凑入口和一条课程摘要。
- 每日考勤点击展开学校打卡流水（时间、方向、通道、结果），按需分页读取。不保存流水到本地，不以流水推算或替换学校每日汇总；异常显示错误而不是伪造空记录。

本次 25 项本地测试通过；真实打卡明细需登录后在手机验证。

考勤页改为周一起始的月历，日期格显示时长和学校判定；点击日期查看当日汇总及打卡时间线。支持前后月份、日期选择器和返回今天；无汇总不等于未达标。

课表页同样使用月历，日期格显示课程数量，选择日期可查看时间、教室和教师；月度门次按教学周过滤计算，保留单双周规则。

## 记住登录

凭据使用微信异步 `setStorage/getStorage` 的 `encrypt: true` 保存与读取，不写入课表/考勤缓存。接口不支持或保存失败时保持本次会话并提示原因，不降级为明文缓存。凭据只用于原有学校 HTTPS 认证接口。

小程序冷启动后先恢复已记住状态，需要数据时自动认证。已有会话过期时最多自动重登一次；密码失效或学校要求二次验证时停止自动重试并清除已保存凭据。网络失败不删除凭据。主动退出、清除数据、换账号会取消旧请求并删除旧登录；未完成的保存或认证不能在退出后恢复登录。

这是自动重新认证，不延长学校服务器会话，也不能保证改密码、二次验证、清理微信缓存后永不需要输入。Cookie 仍只驻留运行内存。参考：[微信加密存储](https://developers.weixin.qq.com/miniprogram/dev/api/storage/wx.setStorage.html)。
